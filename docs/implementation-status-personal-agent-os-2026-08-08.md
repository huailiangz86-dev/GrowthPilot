## 产品边界

Web 是完整的个人成长工作台，承载需要持续浏览、组织、执行、连接和分析的能力：

- 首页 Command Center
- 工作空间 Workspace
- 项目 Project
- 目录、文件和资源入口
- 待办 Task 和 Focus 执行
- 成长目标与周期计划
- Knowledge / Learning
- 常用 App 和已连接应用
- Plugins / Skills / Agent Experts
- Global AI Command Bar
- 工作、学习和成长洞察
- Memory 与个人数据管理
- 历史交易工具

小程序只承担高频、低负担的伴随场景，不追求 Web 功能等价：

- 一句话快速记录
- Morning 启动
- Evening 复盘
- 提醒与今日待办查看
- 当前状态和关键任务查看

## 一、新手引导 + 学习路径进度（P0）

### 1.1 问题

用户第一次进入不知道从哪开始，没有分级引导，知识库有内容但没有"学习计划"。

### 1.2 方案

#### 首次使用引导流

```
首次进入 APP（无交易记录时触发）
    ↓
欢迎页
  "欢迎来到 GrowthPilot"
  "我会帮你建立系统的交易复盘习惯"
    ↓
水平评估（3个问题，不需要账号）
  Q1: 你的交易经验？
      ○ 刚入市（<1年）
      ○ 有经验（1-3年）
      ○ 老手（3年+）

  Q2: 你主要做什么？
      ○ 股票   ○ 加密   ○ 基金   ○ 多品类

  Q3: 你最想改进什么？
      ○ 不知道怎么选股（→推荐基本面学习）
      ○ 总是追涨杀跌（→推荐交易心理）
      ○ 仓位管理混乱（→推荐风控学习）
      ○ 没有复盘习惯（→推荐复盘入门）
    ↓
生成个性化学习计划
  "根据你的情况，推荐以下学习路径："
  📖 新手30天入门计划
  包含 5 个阶段，每天 1 个任务
    ↓
跳转首页，首页顶部显示学习计划进度卡
```

## 二、合规免责体系（P0）

### 2.1 问题

产品含大量交易方法论内容和 AI 分析功能，必须有清晰的免责声明，否则有法律风险。

### 2.2 方案

#### 三层免责机制

**第1层：首次使用协议弹窗**

```
用户首次打开 APP 时弹出：

┌─────────────────────────────────┐
│        用户协议与免责声明          │
│                                  │
│ GrowthPilot 是一款交易学习与复盘   │
│ 工具，提供教育性质的知识内容和      │
│ AI 辅助分析。                     │
│                                  │
│ 重要声明：                        │
│ 1. 本平台不提供任何投资建议         │
│ 2. 不推荐具体股票或交易策略         │
│ 3. 所有知识内容仅供学习参考         │
│ 4. AI 分析基于历史数据，不预测未来   │
│ 5. 投资有风险，交易需谨慎           │
│ 6. 用户的交易决策由用户自行负责      │
│                                  │
│ □ 我已阅读并同意以上条款            │
│                                  │
│         [ 同意并继续 ]             │
└─────────────────────────────────┘
```

同意后存入 `users.settings.disclaimer_accepted = true`，不再弹出。

**第2层：知识/AI 页面底部固定免责**

```
每个知识详情页底部：
"本文由 AI 基于公开资料生成，仅供学习参考，不构成投资建议。"

AI 教练每次回答末尾自动追加：
"以上分析仅供学习参考，不构成投资建议。"

复盘页面底部：
"复盘分析基于历史数据，不代表未来表现。"
```

**第3层：AI 合规守卫（已有 compliance_guard）**

在 AI 教练的 system prompt 中已有规则：
- 不推荐具体股票
- 不给买卖建议
- 不预测行情

增加后置过滤：AI 回答中如果包含"建议买入"、"推荐XX股"等字样，自动替换或拒绝。

### 2.3 实现

```python
# AI 回答后置过滤
BANNED_PATTERNS = [
    r"建议(买入|卖出|购买)",
    r"推荐.{0,4}(股|票|标的)",
    r"目标价.{0,4}\d",
    r"(必涨|必跌|稳赚)",
]

def compliance_filter(reply: str) -> str:
    for pattern in BANNED_PATTERNS:
        if re.search(pattern, reply):
            reply += "\n\n⚠️ 以上分析仅供学习参考，不构成任何投资建议。投资有风险，交易需谨慎。"
            break
    return reply
```

### 2.4 前端

- 首次弹窗：在 `app.tsx` 的 `useDidShow` 中检测
- 知识详情页底部已有免责文字（seed 内容自带）
- AI 教练回答自动追加免责尾巴

## 三、复盘→学习自动闭环（P1）

### 3.1 问题

用户复盘完成后没有自动推荐下一步学习内容，"学→练→盘→学"的闭环断在最后一步。

### 3.2 方案

#### 复盘完成页

```
复盘提交成功后，不直接返回，而是显示「复盘总结页」：

┌─────────────────────────────────┐
│          ✅ 复盘完成！             │
│                                  │
│  使用了：利弗莫尔法                │
│  关联交易：永鼎股份 买入            │
│                                  │
│  ───── AI 学习推荐 ─────          │
│                                  │
│  基于你的复盘内容，推荐阅读：        │
│                                  │
│  📖 利弗莫尔：关键点交易法          │
│     你提到入场时机不够耐心，         │
│     这篇重点讲耐心等待的方法         │
│                                  │
│  📖 《股票大作手回忆录》第5章        │
│     "趋势的力量"与你的情况相关       │
│                                  │
│  📖 塞科塔：截断亏损               │
│     你的止损执行不够果断             │
│                                  │
│       [ 开始学习 ]  [ 返回 ]       │
└─────────────────────────────────┘
```

#### 推荐逻辑

```python
def recommend_after_review(template_id, answers):
    recommendations = []

    # 1. 模版对应的大师知识（必推）
    master_article = find_article(related_template_id=template_id)
    recommendations.append(master_article)

    # 2. 根据回答内容匹配知识
    # 如果回答中提到"止损"相关问题 → 推荐止损知识
    # 如果情绪影响大 → 推荐道格拉斯/交易心理
    # 如果仓位问题 → 推荐范·撒普
    weakness_keywords = extract_weakness(answers)
    for kw in weakness_keywords:
        articles = search_knowledge(kw)
        recommendations.extend(articles[:1])

    # 3. 相关书籍章节
    related_books = find_book_chapters(template_id)
    recommendations.extend(related_books[:1])

    return recommendations[:3]  # 最多推荐3条
```

#### 弱点→知识映射表

| 复盘中发现的问题 | 检测关键词 | 推荐知识 |
|----------------|-----------|---------|
| 追涨/时机不对 | 追涨、入场过早、没等待 | 利弗莫尔关键点、龙头战法首板 |
| 止损不果断 | 扛单、没止损、犹豫 | 塞科塔截断亏损、赵老哥永不补仓 |
| 情绪化交易 | 焦虑、冲动、恐慌、贪婪 | 道格拉斯概率思维、《交易心理分析》 |
| 仓位过重 | 满仓、仓位太大、重仓 | 范·撒普仓位管理、米勒维尼风控 |
| 没有计划 | 没计划、随便买、感觉 | 米勒维尼检查清单、利弗莫尔计划 |
| 拿不住 | 提前卖、过早平仓、没拿住 | 塞科塔让利润奔跑、利弗莫尔耐心 |

### 3.3 API

```
POST /reviews                    — 创建复盘（已有）
  响应增加 recommendations 字段：
  {
    "review": {...},
    "recommendations": [
      {"id": "...", "title": "利弗莫尔：关键点交易法", "reason": "你提到入场时机问题"},
      {"id": "...", "title": "《交易心理分析》第3章", "reason": "与你的情绪状态相关"}
    ]
  }
```

### 3.4 前端

- 复盘提交后跳转到 `pages/review-result/index`（新页面）
- 显示复盘摘要 + AI 推荐知识（3条）
- 点击知识跳转到知识详情页
- "返回"跳回记录列表

## 四、成长轨迹可视化（P1，可后做）

### 4.1 简要方案

在"我的"页面增加「成长报告」入口：

```
本月成长报告
├── 交易表现：胜率 45%→52%（↑7%）
├── 复盘次数：8次（上月5次 ↑60%）
├── 学习时长：120分钟（上月80分钟 ↑50%）
├── 纪律评分：3.2→3.8（↑0.6）
└── 情绪稳定性：2.8→3.5（↑0.7）
```

数据来源：
- 交易表现：records 表统计
- 复盘次数：reviews 表统计
- 学习时长：user_learning_progress 表
- 纪律/情绪：reviews.answers 中的评分题提取

此功能可在 P0/P1 完成后再做。

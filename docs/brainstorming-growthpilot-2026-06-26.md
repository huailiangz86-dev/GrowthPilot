## Key Insights

1. **MVP 只做交易** — 成长平台是愿景不是 v1，先把交易做到极致
2. **标签式记录** — 买入原因+情绪用标签多选，直接支撑"震撼统计"
3. **模块化 + 统一复盘引擎** — 底层通用，场景用模板区分，v2 扩展不重写
4. **渐进式解锁** — 新用户只看交易，30天后解锁认知，90天后解锁知识库
5. **企业广告是 Phase 3+** — v1 只做 C 端订阅
6. **产品名** — 国内"复盘星球"或"GrowthPilot"，海外"GrowthPilot"
7. **复盘是对话不是任务** — AI 主动发起，不是 checklist

## MVP Scope (2-4 weeks)

**只做交易场景的 P0 功能：**
- 交易记录（截图/手动/文件导入 + 标签式原因+情绪）
- 灵活复盘（交易后/每日/手动触发 + "做对了/做错了/下次"）
- AI 模式发现（标签胜率统计 + 时间模式 + 情绪关联）
- 统计中心（收益曲线 + 胜率 + 盈亏比 + 标签分析）
- 首页（今日数据 + AI 建议）

**不做（v2+）：**
- 职业规划、招聘对接、技能图谱、知识库、企业广告

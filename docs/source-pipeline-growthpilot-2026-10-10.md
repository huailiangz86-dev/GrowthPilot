- 当前流程：选择个人原资料与保存版本 → 核对原文 → 选择原件或提取正文 → 准备本地导入清单 → 刷新后查看清单或回查冻结原版本。
- 测试库尚未创建时，可以保存清单并稍后继续，无须凭据、目的地或云端调用。

## 已实现的云端适配流程

目的地保存与上传分别确认。已有 D12 KnowledgeHub 参考库保持只读；个人测试库须在已配置的同一业务空间中。文件类目支持本人指定编号或 `default`。目的地与服务地址冻结后不能改写；同一来源版本、发送模式、空间、库和类目的再次绑定复用已有映射。

逐步处理为：申请上传租约并发送字节 → 登记文件 → 查询解析 → 本人确认追加索引 → 查询该文件及任务的完成状态 → 分页查看本文件切片 / 发送明确允许的检索问题 → 回查本地冻结版本。处理由本人点击触发，不依赖页面保持打开，不自动轮询或后台发送。索引状态查询重复点击有至少三秒间隔保护；长时间关闭页面后重新查看清单。

TXT、Markdown、粘贴文字与文字型 PDF 可上传保存原件。邮件与网页发送已提取的 UTF-8 正文；邮件原有头字段已包含在冻结正文里，原 EML、HTML、PDF 或其他原件继续留在本地。仅保存 URL 的资料不能充当全文导入，需先另存正文快照。上传文件名包含稳定导入编号和来源版本，分别保存原件与上传内容的 SHA256；申请租约使用实际字节的 MD5 和大小。

按官方 SDK 2.6.2 接入 `ApplyFileUploadLease`、二进制 OSS 上传、`AddFile`、`DescribeFile`、`SubmitIndexAddDocumentsJob`、`GetIndexJobStatus`、`ListChunks` 与 `Retrieve`。只向有效 HTTPS 官方 OSS 上传地址发送，关闭环境代理与重定向，不向浏览器返回凭据、签名地址、上传头或租约。

## 去重与失败恢复

本地清单与稳定提交持久化，提交回执丢失可恢复原选择重试。人级锁与运行标识防止两页同时推进同一步。网络请求前提交状态和租期，外部请求期间不持有用户锁；迟到的上传结果不能覆盖后来尝试的租约。原件与原正文版本不修改。

上传失败可重试；临时 OSS 上传不等于登记知识库文件。登记或追加索引明确被服务端拒绝时，可重试当前步骤；登记明确拒绝且租约过期时，可先回到上传步骤再申请临时上传。登记或索引请求结果未知、成功回执缺少编号、或执行中断后超出租期，标记“回执待核对”，不重复写入。

本人提供实际文件编号后，核对云端文件名、大小、类目和唯一导入标签；提供索引任务编号时，核对任务包含这份文件。只保存白名单回执字段、实际请求编号和读取时间。解析失败、任务失败或文档未完成索引均不能显示“索引完成”。

本轮启动默认 `BAILIAN_PERSONAL_IMPORT_ENABLED=false`，云端写入关闭。本地清单支持所有已登录的本人账户；云端连接仍绑定原已确认的本机账户。跨账户不能读取或推进其他人的清单。账户切换清除旧界面，刷新或改变问题/选择后不恢复发送同意。

## 引用回查

云端切片保留真实文件与切片编号；不把云端原文或重排分数当作个人掌握情况。检索结果只发布属于当前映射文件的片段。原文逐字出现在该版本冻结正文中时才返回 Unicode 字符位置；PDF 页码只有真实定位片段完全覆盖匹配时才关联。改写、跨页或找不到对应内容时明确提示核对，不猜测坐标。

复制引用同时保留云端文字、个人来源编号、保存版本、原件与上传内容校验值、业务空间/知识库、文档/切片编号和读取时间。剪贴板不可用时保留可选择文字；来源跳转直接打开对应保存版本，后来修订不改旧映射。

## 重新启动

在项目根目录执行：

```sh
backend/.venv/bin/python backend/scripts/local_trial.py status
backend/.venv/bin/python backend/scripts/local_trial.py prepare
backend/.venv/bin/python backend/scripts/local_trial.py start
```

`status` 读取数据库和迁移版本、模型是否配置，不输出凭据。`prepare` 创建缺失的本地开发库，应用现有迁移；已有版本化数据需要升级时，先生成并检查可读的 PostgreSQL 自定义格式备份。重复执行当前版本不重建数据库或迁移。

`start` 启动后端 8002 和 Web 4010，等待服务就绪。数据库不是当前版本、端口已占用或依赖缺失时停止；启动操作不自动迁移。前台终端保持运行，Ctrl+C 会关闭这次启动的两个服务，数据库内容保留。

配置仍在被忽略的 `backend/.env`，本地备份和验收结果在被忽略的 `backend/.local-trial/`。启动器只接受本机、名称以 `growthpilot_` 开头且以 `_dev`、`_trial` 或 `_test` 结尾的 PostgreSQL 数据库；不会删除或重置已有数据。

## Executive Summary

GrowthPilot 是 AI 投资教练平台。v2 从"股票交易日记"升级为**全品类投资记录+资讯聚合+深度分析+增长引导**的完整平台。

**Slogan:** 每一次交易，都在暴露你的模式。

**v2 vs v1 核心变化：**
- 全品类：股票 + 加密货币 + 基金 + 日常开销 + 外汇期货
- 复盘合并到记录表单（不独立 Tab）
- 首页信息枢纽（Banner + 资讯 + AI 建议）
- 资讯聚合（自选标的精准推送）
- 深度分析（情绪 + 性格 + AI 教练，替代简单统计）
- 增长引导系统（任务 + 签到 + 成就）
- 新 TabBar：首页 / 记录 / 日历 / 分析 / 我的

## Non-Functional Requirements

### NFR-001: 性能
- 记录提交 ≤ 1s
- 首页加载 ≤ 2s（含资讯）
- AI 分析异步不阻塞

### NFR-002: 安全
- 价格字段 AES-256 加密
- user_id 强制过滤
- JWT 7 天过期

### NFR-003: 合规
- AI 不推荐标的、不预测价格
- 所有 AI 输出附免责声明
- 资讯标注来源，不做原创投资建议

### NFR-004: 模块化
- records 通用表支持全品类
- 复盘引擎场景无关
- 新品类只加 scene + 标签集

### NFR-005: AI 成本
- 标签统计/模式发现用 SQL（¥0）
- LLM 只用于：复盘对话 + 性格分析 + 资讯摘要
- 月成本 ≤ ¥500（200 用户）

## Key Design Decisions

### 1. 复盘不再是独立 Tab
交易记录表单底部折叠区："做对了/做错了/备注"。提交后弹出"要写几句复盘吗？"。保留独立"每日复盘"入口但不在 TabBar。

### 2. 日常开销极简化
不用标签体系，只需：金额 + 类别(下拉) + 备注。和交易分开显示但共享日历视图。

### 3. 资讯 = 精准推送
不做新闻 App。只推送用户自选标的/关注行业的相关新闻。用 AI 生成一句话摘要。

### 4. 分析页 4 个子 Tab
统计（数据面板）→ 模式（AI 模式发现）→ 情绪（情绪-行为关联）→ AI 教练（对话+报告）

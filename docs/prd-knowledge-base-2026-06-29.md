## 概述

> **Historical reference:** This knowledge-base module PRD is superseded by `docs/README.md` and the active v3.1 Workspace-first PRD/UX documents. Keep it as feature history only.

为 GrowthPilot 构建知识库模块，形成"**学习 → 实践 → 复盘 → 再学习**"的闭环。知识库与现有 18 套大师复盘模版联动，用户用哪套模版复盘，系统推对应大师的知识内容。

### 业务目标

1. 提升用户留存（日活从交易日延伸到非交易日）
2. 构建内容壁垒（复盘数据 × 知识推荐的闭环，竞品无法复制）
3. 为后续知识付费/AI教练奠定内容基础

### 成功指标

- 知识库模块周打开率 > 40%
- 用户平均学习时长 > 3分钟/次
- 复盘后知识推荐点击率 > 25%

## 用户画像

| 角色 | 特征 | 知识需求 |
|------|------|---------|
| 新手交易者 | 0-1年经验，亏多赚少 | 入门教程、术语解释、基础形态 |
| 进阶交易者 | 1-3年，有自己的方法但不稳定 | 大师方法论深度解读、心理建设 |
| 高手交易者 | 3年+，稳定盈利 | 查漏补缺、新视角、分享自己的方法 |

## 功能需求

### FR-001: 大师框架知识库

**优先级**: Must Have

**描述**: 为已有的 18 套大师复盘模版各配一套知识内容，包括：大师生平、核心理念、方法论详解、实战案例、常见误区。

**验收标准**:
- [ ] 18 位大师各有一个知识专题页
- [ ] 每个专题包含：简介(200字)、核心理念(3-5条)、方法论详解(1000-2000字)、实战案例(1-2个)
- [ ] 内容为原创或 AI 生成，零版权风险
- [ ] 从复盘模版可直接跳转到对应大师知识页

---

### FR-002: 交易术语词典

**优先级**: Must Have

**描述**: 覆盖常用交易术语的中英对照词典，每个术语含定义、实战用法、关联术语。支持搜索和按分类浏览。

**验收标准**:
- [ ] 首批 100+ 核心术语（如 MACD、RSI、止损、打板、龙头等）
- [ ] 每个术语：中文名、英文名、定义(50-100字)、实战用法(1-2句)
- [ ] 支持关键词搜索
- [ ] 按分类浏览（技术指标/K线形态/交易策略/市场术语）

---

### FR-003: 学习路径

**优先级**: Must Have

**描述**: 预设分阶段学习路径，引导用户从入门到进阶系统学习。每个阶段包含若干知识单元，完成后解锁下一阶段。

**验收标准**:
- [ ] 至少 3 条学习路径（新手入门/技术分析/交易心理）
- [ ] 每条路径 5-10 个阶段，每阶段 3-5 个知识单元
- [ ] 学习进度可视化（已学/总数/百分比）
- [ ] 完成阶段有成就提示

---

### FR-004: 复盘后知识推荐

**优先级**: Must Have

**描述**: 用户完成复盘后，系统根据使用的模版和填写的内容，推荐相关知识。

**验收标准**:
- [ ] 复盘完成页展示 1-3 条推荐知识链接
- [ ] 推荐逻辑：模版对应大师的知识 + 用户薄弱项相关
- [ ] 点击可直接跳转到知识详情页

## 非功能需求

### NFR-001: 内容合规

**优先级**: Must Have

**描述**: 所有知识内容不得包含具体投资建议，不推荐具体股票，不承诺收益。

**验收标准**:
- [ ] 所有内容经过合规审查
- [ ] 知识页底部显示免责声明
- [ ] AI 生成内容经过 compliance_guard 过滤

---

### NFR-002: 版权安全

**优先级**: Must Have

**描述**: 所有内容来源合法，版权清晰。

**验收标准**:
- [ ] 自建原创内容：100% 无风险
- [ ] 公共领域书籍：仅使用 1923 年前出版的作品
- [ ] AI 重写内容：不复制原文，用新案例诠释理论
- [ ] 每条内容标注来源类型（原创/公共领域/AI生成）

---

### NFR-003: 性能

**优先级**: Must Have

**描述**: 知识内容加载快速。

**验收标准**:
- [ ] 知识列表页加载 < 500ms
- [ ] 知识详情页加载 < 1s
- [ ] 搜索响应 < 300ms

---

### NFR-004: 离线可用

**优先级**: Should Have

**描述**: 已读过的知识内容支持离线访问。

**验收标准**:

## 数据模型（概要）

```
knowledge_categories  — 知识分类（大师方法论/术语/K线形态/指标...）
knowledge_articles    — 知识文章（title, content_md, category_id,
                        source_type, author, reading_time_min）
knowledge_terms       — 术语词典（term_cn, term_en, definition,
                        usage, category）
learning_paths        — 学习路径（name, level, stages JSONB）
user_learning_progress — 用户学习进度（user_id, article_id,
                          status, read_at, notes）
user_bookmarks        — 收藏（user_id, article_id）
```

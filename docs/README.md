## 一致性基线

- PRD 3.4 的学习应用定位与 P0/P1 队列优先；传统查看独立可用，保留既有功能，新能力先原型再真实接入。
- 产品面向个人，围绕目标、工作、学习应用与复盘形成成长闭环；团队管理与企业考核不进入本轮。
- Web 主导航规划为今日、工作、学习、成长、我的；任务正文和日历在工作，目标/计划/复盘/回顾在成长，应用与能力在我的，Agent 全局及事项内可达。正式 `/app` 已按五入口改造，日复盘可从成长进入。
- 小程序只做快速记录、Morning、Evening、提醒和今日任务/状态查看；复杂组织、分析和能力管理回到 Web。
- Workspace 是承载层，默认我的空间；Project 为可选轻量组织，Goal、Growth Plan、Task、Knowledge 承载工作和成长。C1 已有任务正文/成果与多段起止安排，截止时间与投入分开。
- Workspace Event 记录事实，Memory 提供长期上下文，Growth Insight 提供带证据的分析；三者不能取代领域对象的当前状态。
- Onboarding 使用一句自然语言生成首个 Workspace、Project、Goal、Plan、Task 和 Learning 入口，用户确认、纠正或拒绝，不填写长表单。
- 旧交易能力和 Memory CRUD 保留为历史工具/数据管理能力，不出现在默认主线。
- 下一阶段以 PRD 3.3、各文档顶部补充和 D0–D3 Story/Sprint 为依据，C2–C4 能力按场景复用；历史交付保留，规划项不能标为已实现。后台创建待办只算调度，执行成功需要实际正文、成果或外部资源回执。
